# PDF Merger

Merge mixed `PDF`, `JPG`, and `JPEG` files, reorder them, and download one combined PDF.

**Live:** [https://immmune-etude.github.io/collate/](https://immmune-etude.github.io/collate/)

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
npx gh-pages -d dist
```
