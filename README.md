# PDF Merger

Merge mixed `PDF`, `JPG`, and `JPEG` files, reorder them, and download one combined PDF.

**Live:** [https://pdf-merger-mu-ashen.vercel.app](https://pdf-merger-mu-ashen.vercel.app)

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
npx vercel --prod
```
